# Dulce Antojo · Tienda de postres caseros (ejemplo)

Página de ejemplo para clase: una tienda online de postres caseros en Medellín, hecha en un solo archivo HTML, sin servidor ni base de datos.

- Catálogo de 6 productos con precio en pesos colombianos (COP)
- Carrito con cantidades, subtotales y total
- Botón "Pedir por WhatsApp" que arma el mensaje con el pedido

## Cómo usarla

Abre `index.html` en el navegador. Para cambiar productos, precios o el número de WhatsApp, edita la lista `productos` y la constante `WHATSAPP_NUMERO` dentro del archivo.
